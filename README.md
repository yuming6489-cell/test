# 熊貓啪屁屁！Panda Bonk

可免費部署在 GitHub Pages 的純前端小遊戲。無需伺服器、npm 或建置工具。

## 遊戲方式

- 點擊／觸碰棕熊的屁屁即可得分，連擊有加成。
- 每局 30 秒，自動儲存裝置上的最高紀錄。
- 支援電腦與手機、音效切換、重新開始。
- 電腦可按空白鍵開始遊戲或擊打（方便測試）。

## 免費部署 GitHub Pages

1. 在 GitHub 建立一個 **Public** repository（例如 `panda-bonk`）。
2. 上傳本資料夾的 `index.html` 到儲存庫根目錄，Commit changes。
3. 到 **Settings → Pages**。
4. **Build and deployment → Source** 選 **Deploy from a branch**。
5. Branch 選 **main**、資料夾選 **/(root)**，按 **Save**。
6. 網頁網址通常是 `https://你的帳號.github.io/panda-bonk/`。

`index.html` 為完整遊戲，打開即可在瀏覽器運行。標題字體使用 Google Fonts，無網路時會自動切換到系統字體。
