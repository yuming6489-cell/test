# BOUNDLESS 無界之境 V0.5

這是戰鬥演出版的 GitHub Pages 網站檔。圖片、配樂、音效與遊戲程式都在 index.html 內，解壓後可直接用瀏覽器開啟。

## 發佈到 GitHub Pages

1. 將解壓後的 index.html 和 .nojekyll 放在 GitHub 儲存庫的 main 分支根目錄。
2. 開啟儲存庫的 Settings → Pages，將 Source 設為 Deploy from a branch。
3. 選擇 main 與 /(root)，然後按 Save。
4. 發佈完成後，在 Pages 設定頁點 Visit site。

[GitHub Pages 官方設定說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
